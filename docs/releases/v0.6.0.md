# Spyro Menu Voices v0.6.0

This is the first release I consider properly finished.

The mod restores the unused menu voice lines in Spyro Reignited Trilogy without needing Spyro Workshop or another mod to provide its hooks.

## What it does

- Says **“Spyro Reignited Trilogy”** when the real trilogy title menu appears.
- Says **Spyro the Dragon**, **Spyro 2: Ripto's Rage**, or **Spyro: Year of the Dragon** when that game is highlighted.
- Stops the current line immediately if you move to another game.
- Says the trilogy title again when you back out of the game selector.
- Keeps the profile/save-loading screen silent.
- Does not repeatedly replay the title line when a normal popup closes.

All four WAV files are embedded in the ASI.

## Install

Download `SpyroMenuVoices.asi` from the Assets section and place it beside:

```text
Falcon\Binaries\Win64\Spyro-Win64-Shipping.exe
```

You need an ASI loader. If your existing Spyro mod setup already loads `.asi` files from that folder, just drop this one in with the others.

## What changed while this was being tested

The final menu detection is based on real runtime events rather than guessed delays.

The trilogy selector is tracked through `FalconGameplayStatics::GetGameIndex`, which follows the highlighted game.

The trilogy title is tracked through `UserWidget::OnAddedToFocusPath` on the actual `UI_Title_C_*` widget.

Earlier test builds tried timing-based approaches. Those were removed after they caused false title announcements on the save screen and between slow selector inputs.

v0.6.0 does not use those timers.
